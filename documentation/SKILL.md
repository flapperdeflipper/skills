## What I do

- Create clear explanations of code functionality
- Write API documentation with proper structure
- Include practical code examples
- Use user-friendly language appropriate for the audience
- Generate README files, guides, and reference docs

## When to use me

Use this skill when you need to document code, write README files, create API docs, or explain complex systems.

## Documentation principles

1. **Clarity**: Explain concepts simply without jargon
2. **Completeness**: Cover all necessary information
3. **Examples**: Show, don't just tell
4. **Structure**: Use headings, lists, and formatting effectively
5. **Audience-aware**: Adapt language to the intended reader
