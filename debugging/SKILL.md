## What I do

- Apply systematic debugging methodology
- Analyze error messages and stack traces
- Identify root causes through logical deduction
- Suggest targeted fixes with minimal changes
- Verify fixes don't introduce new issues

## When to use me

Use this skill when encountering errors, unexpected behavior, or failing tests.

## Debugging methodology

1. **Reproduce**: Ensure you can reliably reproduce the issue
2. **Isolate**: Narrow down the scope of the problem
3. **Hypothesize**: Form theories about the root cause
4. **Test**: Verify hypotheses with targeted tests
5. **Fix**: Apply minimal, targeted fix
6. **Verify**: Confirm the fix works and doesn't break anything

## Common debugging techniques

- Binary search through code changes
- Add logging/print statements strategically
- Check recent changes with git diff/blame
- Review error handling paths
- Validate assumptions about data/state
