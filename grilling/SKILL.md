# Grilling

Adapted from [mattpocock/skills](https://github.com/mattpocock/skills).

Interview the user relentlessly about every aspect of this until you reach a shared understanding. Walk down each branch of the decision tree, resolving dependencies between decisions one by one. For each question, give your recommended answer and say why.

Ask the questions **one at a time**, waiting for an answer before continuing. Asking several at once is bewildering and produces shallow answers.

If a *fact* can be found by exploring the environment (filesystem, git history, cloud APIs, official docs) look it up rather than asking. The *decisions* are the user's: put each one to them and wait.

Push back when an answer is wrong or a better approach exists, and say why. Name trade-offs unasked.

Do not act on any of it until the user confirms you have reached shared understanding.
